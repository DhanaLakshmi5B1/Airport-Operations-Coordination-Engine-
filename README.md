### Infosys Internship 7.0 | Milestone 1

**SkyOps** is a React-based Airport Operations Coordination Dashboard that monitors weather conditions across multiple airports and displays weather-based operational alerts through an interactive dashboard.

## 📌 Project Overview

The SkyOps Airport Operations Coordination Engine provides a centralized dashboard to monitor airport weather conditions and identify potential weather-related operational concerns.

The application fetches current weather information from the Open-Meteo API and presents it in a simple, user-friendly interface.

## 🎯 Objective

To develop an interactive airport operations dashboard that displays weather information, generates weather-based alerts, and helps users monitor airport conditions efficiently.

## ✨ Key Features

- 🌦️ **Live Weather Monitoring** – Fetch current weather data using the Open-Meteo API.
- ✈️ **Multiple Airport Monitoring** – View weather conditions for selected airports.
- 🔄 **Refresh Weather** – Fetch updated weather information using the refresh button.
- 🚨 **Automatic Weather Alerts** – Display alerts based on weather conditions.
- 🎚️ **Severity Filters** – Filter alerts by severity, including High and Medium.
- 🔍 **View Details** – View additional information about selected alerts.
- 🏢 **Airport Management** – Add or remove airports, if supported by the current version.
- 📋 **Flight Operations Table** – Display flight operation records.
- 🎨 **Modern Dashboard UI** – Clean, organized, blue-themed interface.

## 🚀 Installation and Setup

### Prerequisites

- Node.js and npm
- Git
- Visual Studio Code
- Internet connection

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the Project Folder

```bash
cd AirportWeatherAlerts
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open the Application

Open the local URL displayed in the terminal, for example:

`http://localhost:5173/`

### Step 6: Build the Project

```bash
npm run build
```
